### 🤖 [Sangam: Universal AI Chat Platform](https://github.com/keshria-hacker/sangam) &nbsp;`flagship`

> Privacy-first AI workspace that puts 11 cloud and local LLM providers behind one API layer.

- **Multi-provider:** OpenAI, Anthropic, Gemini, Groq, NVIDIA NIM, OpenRouter, Ollama and more, with real-time token streaming over Server-Sent Events.
- **Document chat (RAG):** text extraction from PDF, DOCX, XLSX, PPTX, CSV and code, then chunking, embedding and retrieval with ChromaDB.
- **Secure by design:** async backend with SQLAlchemy + Alembic migrations, encrypted API keys, scrypt password hashing, CSRF protection, rate limiting and prompt-injection detection.
- **Production-minded:** Docker/Compose, GitHub Actions CI with an enforced test-coverage gate, vanilla-JS frontend with light/dark themes.

`Python` · `FastAPI` · `ChromaDB` · `SQLAlchemy` · `Docker`

<br>

### 🎓 [Student Placement Analysis System](https://github.com/keshria-hacker/student-placement-analysis)

> ML-powered web app that predicts a student's placement chances and recommends skills to close gaps.

- Trained a **Random Forest** classifier with feature scaling on a 600-record dataset.
- Login/registration (Flask-Login), student and placement-drive management, a **Chart.js** analytics dashboard and a skill-gap recommendation feature.

`Flask` · `scikit-learn` · `Chart.js`

<br>

### 💸 [SplitPay: Android App](https://github.com/keshria-hacker/SplitPay-Android)

> Splits one large UPI payment into smaller parts and pays each through your installed UPI app.

- Native Android app, **released as public beta (v1.0 to v1.2)**, using Android intents.
- Exact integer split arithmetic, QR scanning/generation and a JavaScript-Kotlin bridge; fully offline with no network requests.

`Kotlin` · `WebView` · `JavaScript`
